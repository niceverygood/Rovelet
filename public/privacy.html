기기 내 게임 정보
게임 진행, 마을과 시설 상태, 금화, 진행 중인 공사, 전투 이어하기 기록과 설정을 저장합니다. 설정에는 언어, 음량, 진동, 움직임 감소 선택이 포함됩니다. 프로필·전투 기록의 보조본과 처리 중인 저장 상태도 보관합니다.
웹에서는 브라우저의 로컬 저장소를 사용합니다. 네이티브 앱에서는 로컬 저장소와 기기의 Preferences 저장소에 보조본을 저장합니다. 게임 코드에는 계정 가입, 광고 연결, 분석 업로드 또는 게임 전용 클라우드 동기화 기능이 없습니다.

게임 파일과 네트워크
네이티브 설치본의 게임 파일과 시각 자원은 앱에 포함됩니다. 웹판은 게임 파일을 호스팅 서버에서 불러옵니다. 글꼴은 기기에 설치된 글꼴을 사용하고 음악과 효과음은 게임에서 합성합니다. Android 앱에는 인터넷 권한이 선언되어 있습니다.

운영체제 백업과 기기 이전
Android 앱의 시스템 백업 허용 설정은 켜져 있으며 별도의 백업·데이터 추출 규칙을 지정하지 않습니다. 운영체제나 기기의 백업·이전 기능이 앱 데이터를 다룰 수 있습니다. 적용 범위는 플랫폼과 사용자 설정에 따르며 게임의 별도 클라우드 저장 기능으로 제공되는 것은 아닙니다. 모든 저장 정보가 항상 기기 안에만 남는다고 보장하지 않습니다.

저장 정보 관리
브라우저 사이트 데이터 또는 운영체제의 앱 데이터 관리 기능을 사용할 수 있습니다. 로컬 데이터를 지우면 진행과 설정을 잃을 수 있습니다. 운영체제 백업의 보관·복원·삭제 범위는 해당 서비스와 기기 설정에 따릅니다.

English

Game information stored locally
The game stores progress, village and facility state, coins, construction jobs, battle continuation records and settings. Settings include language, volume, vibration and reduced motion. It also keeps backup copies and pending save state for profiles and battles.
The web version uses browser local storage. The native app keeps local storage and auxiliary copies in the device Preferences store. The game code has no account registration, advertising integration, analytics upload or game-operated cloud synchronization feature.

Game files and network
The native installation includes its game files and visual assets. The web version loads game files from its hosting server. Fonts use locally installed fonts, and music and effects are synthesized by the game. The Android app declares the Internet permission.

Operating-system backup and device transfer
The Android application allows system backup and does not specify separate backup or data-extraction rules. Operating-system or device backup and transfer features may handle app data. Their behavior depends on the platform and user settings; the game does not offer a separate cloud-save service. We do not guarantee that every saved value always remains only on the device.

Managing saved information
You can use browser site-data or operating-system app-data management tools. Clearing local data may remove progress and settings. Retention, restoration and deletion of operating-system backups depend on the relevant service and device settings.
